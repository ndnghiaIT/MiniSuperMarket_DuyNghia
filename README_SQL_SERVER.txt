INSTANT FOOD - KET NOI SQL SERVER

Project da duoc cau hinh de ket noi SQL Server voi tai khoan sa:
Server=.; Database=InstantFoodDb; User Id=sa; Password=123456

Neu tai khoan sa cua may ban dung mat khau khac 123456, sua Password trong:
MiniSupermarket.API\appsettings.json

File SQL: InstantFoodDb_SQLServer_sa.sql

Trong SSMS, ket noi Database Engine vao server . (hoac ten instance dang hien tren may),
chay file SQL de tao database InstantFoodDb, sau do mo solution MiniSupermarket.API.sln bang Visual Studio.

WinForms dang goi API tai http://localhost:7049/api/; hay chay MiniSupermarket.API truoc.
